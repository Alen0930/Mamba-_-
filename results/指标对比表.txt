================================================================================
一、五种方法核心指标对比
================================================================================

方法                          Stop步数        FC值         达到Stop    达到FC
--------------------------------------------------------------------------------
mamba（随机初始化）             720           0.8430         True        True
degree                         276           0.3900         True        True
pagerank                       267           0.3820         True        True
CoreHD                         238           0.4380         True        True
mamba（训练后）                 261           0.3770         True        True
--------------------------------------------------------------------------------

指标说明:
  - Stop步数 : 使最大连通分量(LCC)降至原始网络 10% 所需移除的节点数（越小越好）
  - FC值     : 使最大连通分量降至原始网络 1%（网络瓦解阈值）所需移除节点占总
               节点数的比例（越小越好）

================================================================================
四、结论
================================================================================

1. 训练后的 Mamba 在 Stop 步数指标上超越 degree 与 pagerank 两个经典基线，
   逼近监督信号 CoreHD（差距 9.7%）。
2. 在 FC 值（网络瓦解阈值）指标上，训练后 Mamba 全面领先所有对比方法。
3. 模型在独立测试网络上（seed=2026，与训练集无交集）表现稳定，
   证明学习到的是通用拓扑拆解规律。
